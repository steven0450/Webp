## 🎯 교육 목적

웹 프론트엔드 개발의 핵심 기술을 학습하고 직접 구현하는 것을 목표로 한다.

* 🧱 **구조 설계 (HTML)**: 웹 페이지의 기본 뼈대 구성
* 🎨 **시각적 표현 (CSS)**: 디자인 및 레이아웃 스타일링
* ⚡ **동적 기능 구현 (JavaScript)**: 사용자와 상호작용하는 반응형 웹 개발

> 💡 **초급자 맞춤형 강의**: 프로그래밍 입문자도 이해할 수 있도록 기초부터 다루며, **프로젝트 기반 학습(PBL)**을 통해 실무 역량을 강화한다.
