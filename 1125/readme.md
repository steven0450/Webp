# 2026. 11. 25. 수업 내용

## 11월25일 저녁 신청 받기

Google Apps Script(GAS)와 Google 스프레드시트를 DB로 활용해 저녁 메뉴 신청을 받고 완료 메시지를 띄우는 웹앱.

### 주요 기능
- **신청 폼 제출:** 이름, 음식, 하고 싶은 말 입력 및 전송
- **스프레드시트 저장:** 제출 데이터를 Google 스프레드시트에 자동 기록
- **완료 화면 전환:** 저장 완료 시 `"답장 감사합니다."` 메시지 노출

### 파일 구성
- `Code.gs`: HTML 렌더링(`doGet`), 스타일 포함(`include`), 시트 데이터 저장(`saveResponse`)
- `index.html`: 신청 폼 UI 및 `google.script.run` 비동기 제출 처리
- `style.html`: 배경 그라데이션, 카드 레이아웃, 폼 스타일 정의

### 시트 구조 (`A1:C1`)
| 열 | 헤더 | 내용 |
| :--- | :--- | :--- |
| `A` | 이름 | 신청자 이름 |
| `B` | 음식 | 희망 메뉴 |
| `C` | 하고 싶은 말 | 전달 메모 |

### 배포 방법
1. Google 스프레드시트 생성 후 **[확장 프로그램] > [Apps Script]** 실행
2. `Code.gs`, `index.html`, `style.html` 코드 작성
3. **[배포] > [새 배포]** → 유형: **웹 앱**, 실행 권한: **나**, 액세스 권한: **모든 사용자** 설정 후 배포
4. 코드 수정 시 **[배포 관리] > 수정 > 새 버전**으로 재배포
